Level 1 — Easy (1–10)
1. Check whether a number is positive, negative, or zero.
2. Check whether a number is even or odd.
3. Check whether a person is eligible to vote based on age.
4. Find the greater of two numbers.
5. Check whether a number is divisible by 5.
6. Find the largest of three numbers.
7. Check whether a student passed or failed (passing marks: 40).
8. Print the day of the week using a number from 1 to 7 (switch).
9. Build a calculator for addition, subtraction, multiplication, and division using switch.
10. Print the month name using a number from 1 to 12 (switch).











Level 2 — Easy to Medium (11–20)
11. Check whether a year is a leap year.
12. Check whether a character is a vowel or consonant.
13. Calculate a student's grade based on marks: A (90–100), B (75–89), C (60–74), D (40–59), F (below 40).
14. Check whether three given sides can form a valid triangle.
15. Calculate profit, loss, or neither using cost price and selling price.
16. Calculate a discount: up to ₹5,000 = 0%, ₹5,001–₹7,000 = 5%, ₹7,001–₹9,000 = 10%, above ₹9,000 = 15%.
17. Create a traffic signal program using switch.
18. Calculate a movie ticket price based on age: under 5 = free, 5–17 = ₹100, 18–59 = ₹200, 60+ = ₹120.
19. Check whether a number lies within the range 1–100.
20. Check login credentials using a username and password.







Level 3 — Medium (21–30)
21. Calculate an electricity bill using these rates: up to 100 units = ₹4.2/unit, 101–200 = ₹6/unit, 201–400 = ₹8/unit, above 400 = ₹13/unit.
22. Calculate a progressive electricity bill using the same rates for each individual slab.
23. Check whether a student is eligible for admission based on marks and attendance.
24. Calculate an employee's bonus based on years of service.
25. Check whether a withdrawal is allowed based on account balance and withdrawal amount.
26. Determine whether a given date is valid, including leap-year rules.
27. Calculate shipping charges based on order value.
28. Check whether a password is weak, medium, or strong.
29. Sort three numbers in ascending order without using a sorting method.
30. Calculate a final salary after allowances, bonus, and deductions.
Level 4 — Hard (31–40)
31. Calculate income tax using progressive tax slabs.
32. Build an e-commerce bill calculator with discounts, shipping, and taxes.
33. Calculate a cab fare using distance slabs, waiting time, and peak-hour charges.
34. Build a bank transaction validation program with a daily withdrawal limit.
35. Calculate an electricity bill with a surcharge for bills exceeding ₹2,000.
36. Calculate a restaurant bill with discounts, tax, and an optional tip.
37. Build an exam result system with subject-wise passing marks and an overall percentage requirement.
38. Determine loan eligibility based on income, credit score, and existing obligations.
39. Calculate an insurance premium based on age, vehicle type, and claim history.
40. Build a shopping checkout program with product selection, stock validation, quantity discounts, and final billing.
Practice order: Finish questions 1–10 before moving to Level 2. Don't look up solutions while attempting them.
